# 数据目录

本仓库**不随附**任何上游方案的数据文件。请自行取得后放进本目录，再按 `profiles/README.md` 的格式写一份配置。

## 需要放入的文件

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `roots.tsv` | `id<TAB>码对<TAB>字形数<TAB>字形串` | 由上游的「字根归并表」抽出（本项目提供 `tools/extract_roots.sh`，输入是一份 PDF） |
| `拆分方案.txt` | `字<TAB>拆分字形串` | 上游方案的全量拆分 |
| `原码编码.yaml` | Rime 风格 `字<TAB>码<TAB>权`（或纯 `字<TAB>权`） | 上游方案的码表 / 字频 |
| `nfkc.tsv`（可选） | `原字形<TAB>目标字形` | 康熙部首等归一化，用于把变体并回同一根 |
| `forced.tsv`（可选） | `码<TAB>输出` | 强制占位，例如把 ，。、； 固定在 `, . / ;` 四个键上 |

`std/level-{1,2,3}.txt` 是《通用规范汉字表》三四级字表，属于国家标准、可以随仓库分发，已入库。

## 关于虎码

虎码（虎爪虎码）的字根划分、拆分方案与码表版权归作者所有，本仓库不作分发。
作者的数据更新重心在 QQ 群，GitHub 上的镜像往往滞后；请从官方渠道获取，
若需再分发请先取得作者同意。
